# KSPHP Plus gikonekos Archive

Historical development archive for **KSPHP Plus gikonekos Edition**.

This repository contains old versions, development materials, test files, and other historical records related to the development process. It is not intended for normal installation or usage.

## Quick Start

| Goal | Go here |
|------|---------|
| Install and use the current version | → [ksphp-plus-gikonekos](https://github.com/gikonekos/ksphp-plus-gikonekos) |
| Browse development history files | this repository |
| See the upstream project | → [Heyuri/ksphp-plus](https://github.com/Heyuri/ksphp-plus/) |

## Related Projects

| Repository | Relationship |
